# Каракурт: ночная смена

Тема Sharrowkin Jam: **ПАУК ПРОТИВ ЧЕЛОВЕКА / Spider vs Human** (объявлена пользователем 30 октября 2026).

Игрок — маленький паук на ночной кухне. Человек видит вредителя, а паук всего лишь собирает ужин. Поставить ловушки, поймать 8 мух и вернуться в гнездо до утра. Фонарик выдаёт положение, тапок заставляет двигаться.

Браузерная одиночная игра, HTML + TypeScript + Canvas 2D, Vite. Без установки, аккаунта, оплаты, внешних ассетов и сервера. Публикация: GitHub Pages. Всё игровое содержимое создаётся внутри Sharrowkin после объявления темы.
