# Каракурт: ночная смена

Тема Sharrowkin Jam: **ПАУК ПРОТИВ ЧЕЛОВЕКА / Spider vs Human** (объявлена 30 октября 2026).

Игрок — каракурт на ночной кухне. Человек сидит у стены справа: светит налобным фонарём и замахивается тапком. Паук ловит мух паутиной, прячется в укрытиях, а когда яд набран, кусает руку человека — так история «каракурт чуть не укусил основателя» заканчивается победой паука.

Браузерная одиночная игра, HTML + TypeScript + Canvas 2D, Vite. Без установки, аккаунта, оплаты, внешних ассетов и сервера. Публикация: GitHub Pages. Всё игровое содержимое создаётся внутри Sharrowkin после объявления темы.
